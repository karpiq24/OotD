# OotD Campaign Wiki

This is the digital home for the **Odyssey of the Dragonlords (OotD)** D&D campaign. 

It is a static site generated by [Quartz](https://quartz.jzhao.xyz/), styled as a wiki for easy navigation of our sessions, lore, and world atlas.

🌐 **Live Site**: [https://karpiq24.github.io/OotD/](https://karpiq24.github.io/OotD/)

## 🚀 Getting Started

### Prerequisites
- Node.js v22+
- npm v10.9.2+

### Running Locally
To preview the wiki on your machine:

```bash
npx quartz build --serve
```

Then open `http://localhost:8080` in your browser.

## 📂 Project Structure

- **`content/`**: The heart of the wiki. All markdown files live here.
    - `01-Sessions/`: Recaps of our adventures.
    - `02-People/`: NPCs, PCs, and Factions.
    - `03-Locations/`: Maps and geography.
    - `04-Items-and-Loot/`: Inventory and artifacts.
    - `05-Lore/`: History, races, and religion.
    - `06-Rules/`: House rules.
    - `07-Handouts/`: Collected handouts and images.
    - `assets/`: Images and videos used in the wiki.
- **`input/`**: Staging area for new session recaps and assets before processing.
- **`scripts/`**: Utility scripts for wiki maintenance.
    - `update_indexes.py`: Regenerates index files across content directories.
    - `fix_image_paths.py`: Fixes image paths in markdown files.
- **`quartz/`**: Quartz framework source files.
- **`quartz.config.ts`**: Configuration for the site (plugins, theme, etc.).
- **`quartz.layout.ts`**: Page layout definitions.

## 🤖 AI-Assisted Wiki Management

This project includes AI workflows and skills to automate session logging and wiki maintenance.

### Workflows
- **`/process-session`**: Process a single RPG session recap from `input/` to `content/01-Sessions/`. Handles asset relocation, entity linking, and wiki updates.
- **`/generate-session-recap`**: Generates a session recap, images, and video prompts from a transcript.

### Skills
- **`rpg-wiki-manager`**: Extracts entities (NPCs, Locations, Items, Lore, Handouts) from RPG session recaps and input files, updating the wiki structure.
- **`rpg-illustrator`**: Generates detailed image prompts and renders images using Nano Banana Pro.
- **`rpg-summarizer`**: Generates a narrative session recap from a transcript.
- **`rpg-timeline-manager`**: Appends session events to the campaign timeline.
- **`rpg-video-scripter`**: Generates video script prompts for session events.

### Rules
The agent follows specific rules for:
- **Auto-updating index files**: Run `python3 scripts/update_indexes.py` after content changes.
- **Wikilink standards**: Simplified Obsidian-compatible wikilinks without paths or extensions.
- **Transcript processing**: Always read the full transcript before summarizing.

See `.agent/` directory for full workflow and skill definitions.
